# Brewlette

A beer roulette / spinning-wheel app for bars. Spin the wheel, land on a beer.

## Stack

- React + Vite
- HTML Canvas wheel
- Browser `localStorage` (no backend)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static assets land in `dist/` and can be served by Nginx.
